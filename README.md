# Travel-Guide 🌍

A full-stack travel planning and guide application designed to help users explore destinations, manage itineraries, and discover recommendations.

## 🚀 Features
* **Interactive Frontend:** Built with HTML and JavaScript for a responsive, user-friendly interface.
* **Backend Integration:** Powered by Python for handling server-side logic and data processing.
* **Live Deployment:** Automatically deployed and hosted via GitHub Pages.

## 🛠️ Tech Stack
* **Frontend:** HTML, JavaScript
* **Backend:** Python
* **Hosting:** GitHub Pages
